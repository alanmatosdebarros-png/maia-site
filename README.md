# Maia · protótipo do site

Protótipo navegável da Maia, agência de conteúdo e social media para pequenas empresas.

Páginas: início, planos, simulador, como funciona, painel (demonstração), mídia paga e contato.

O que é demonstrativo: conteúdos do painel, formulário de contato (não envia), calendário de exemplo.
O que funciona: navegação, simulador completo, troca de planos, aprovação e pedido de ajuste no painel, resumo levado ao contato.

Os arquivos em `src/` são as páginas sem cabeçalho e rodapé; `python3 build.py` gera os `.html` da raiz.
